# Course of Empire — Destruction (UI fidelity study)

**Work:** *The Course of Empire: Destruction* (1836), Thomas Cole (1801–1848).

**Artwork rights:** The original 1836 painting is in the public domain by age. The bundled derivative is a resized, Gaussian-pre-blurred WebP of the digitized artwork from the [Wikimedia Commons file page](https://commons.wikimedia.org/wiki/File:Cole_Thomas_The_Course_of_Empire_Destruction_1836.jpg).

**Retrieval:** 2026-11-28, via [Commons Special:FilePath](https://commons.wikimedia.org/wiki/Special:FilePath/Cole_Thomas_The_Course_of_Empire_Destruction_1836.jpg?width=2048). The owner separately supplied an image of the same painting in chat. The originally described LICENSE.md and asset directory were not present in the checked-out workspace, so this provenance file was created during implementation rather than claimed to have been received.

**Transformation:** Local, offline PIL resize to 1600 × 993, Gaussian radius 8 px, static WebP quality 75; 20,710 bytes. The original JPEG was kept in an ignored private workspace, not committed.

**Scope:** As of 2026-11-28 the owner explicitly authorized moving the glass Today artwork into the live web/desktop frontend. This note records artwork provenance, not independent legal sign-off on the Commons digital reproduction; recheck any required file-page conditions before external distribution or release.
