# tasks: scoped rules (adds to the root AGENTS.md)

- One card per task using the template in `docs/15-agent-workflow.md` section 3. A card is Ready only when dependencies are done and acceptance criteria are testable.
- Do not expand a card's scope; you may split it. Update the status marker (`[ ]`, `[~]`, `[x]`) when you start and finish.
- Use the `lyceum-implement-task` skill to execute a card.
