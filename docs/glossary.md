# Glossary

- **Concept:** an idea the learner must understand (for example "chain rule").
- **Skill:** something the learner must be able to do (for example "differentiate a composite function").
- **Concept graph:** concepts linked by prerequisites.
- **Mastery (`pKnown`):** estimated probability the learner knows a concept, with uncertainty.
- **Retrievability:** probability of recalling something now (from the spaced-repetition model).
- **Hint ladder:** escalating hints from nudge to full solution (levels 0 to 5).
- **Calibration:** how well confidence matches correctness.
- **Domain Profile:** a plug-in that teaches the engine a subject.
- **Gateway:** the layer that talks to any language model provider.
- **Tier:** `fast`, `standard`, or `deep`; a kind of task the engine routes to a model.
- **Readiness:** estimated exam performance, shown as a range with reasons.
- **Exam wrapper:** post-exam classification of each miss (gap, procedure, slip, misread, time, anxiety).
- **Weakness loop:** detect, trace root cause, repair, confirm.
- **Source label:** provenance tag on content (`materials`, `general`, `tool`, `web`).
- **Projection:** derived state rebuilt from events.
- **Port:** an interface through which the engine touches the outside world.
- **ADR:** architecture decision record.
- **Math leak:** subject-specific logic that accidentally got into the core.
