# docs: scoped rules (adds to the root AGENTS.md)

- Specs are contracts. Change them in the same PR as the behavior they describe; wrong docs are bugs. Do not invent behavior; if the spec is silent, ask.
- Significant decisions go in an ADR (`lyceum-adr` skill); only the human lead marks an ADR accepted.
- Keep `docs/STATUS.md` truthful: newest entries first, short, with `BLOCKED:` lines where a human is needed.
- Files in `design-reference/` are internal reference only; never copy them into product assets.
