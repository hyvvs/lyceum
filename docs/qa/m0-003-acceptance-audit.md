Add a test-only Storybook index inventory comparing all 141 `Primitives/*` story IDs to the axe-scan matrix; scan **every** story under its correct interaction state (including Button's 13 currently omitted stories and Toast timed stories with stable fake-clock sampling), not merely `addon-a11y` installed. Keep existing per-component open-state and integration scans. Avoid concurrent duplicate axe scans and respect the current hosted Verify timeout. Fail CI on **any** uncovered story; do not weaken the original "all stories" requirement.
2. **Live preference/portal + forced-color integration:** add a narrow test-only Playwright file that changes the theme/contrast/transparency/motion preference **without remounting** a Dialog + Select composition. Assert computed theme/solid presentation, preserved active focus/portal accessibility and restored original trigger, no extra `inert` or blur, 320×256/32px and OS forced-colors/reduced-motion; capture small full/opaque fallback visual evidence for independent review. Do not implement a production Settings UI (M0-004/M0-014) or new focus manager.
3. **Human accessibility review:** screen-reader/keyboard review of focus transitions and critical accessible names on supported assistive technology; record exact platform/AT. Existing axe tests do not assert every real AT combination. Record component-level solid fallback visual signoff without substituting for M0-017's separate full-screen visual comparison.

These are proposals for separately reviewed scoped QA changes, **not** additions to the current decision/audit PR. An unresolved acceptance result must never be converted to PASS merely because a hosted run is green.
